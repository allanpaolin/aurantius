# AURANTIUS

Landing Page oficial da **AURANTIUS**, empresa especializada em estratégia, tecnologia e inteligência artificial aplicada aos negócios.

O projeto foi desenvolvido com foco em uma experiência digital premium, priorizando simplicidade, clareza, performance e uma identidade visual atemporal.

---

## 🌐 Website

https://aurantius.com.br

---

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
- Lucide Icons
- Google Fonts (Inter)

O projeto foi desenvolvido sem frameworks front-end, garantindo maior controle sobre a arquitetura, excelente desempenho e baixo consumo de recursos.

## 🎨 Filosofia de Design

A identidade digital da AURANTIUS foi construída sobre alguns princípios fundamentais:

- Clareza acima de complexidade.
- Tecnologia como meio, não como protagonista.
- Sofisticação através dos detalhes.
- Minimalismo intencional.
- Espaço em branco como elemento de comunicação.
- Animações discretas e naturais.
- Consistência visual em todos os componentes.

O objetivo não é impressionar através de efeitos, mas transmitir confiança através da qualidade da experiência.

## ⚙️ Executando localmente

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/aurantius-site.git
```

Abra a pasta do projeto e execute o arquivo `index.html` em qualquer navegador moderno.

Para desenvolvimento, recomenda-se utilizar a extensão **Live Server** do Visual Studio Code.
